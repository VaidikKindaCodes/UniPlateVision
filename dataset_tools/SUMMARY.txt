Scripts and files added
-----------------------
All new files are under dataset_tools/ and a lightweight dataset skeleton under dataset/.

1- dataset_tools/inspect_dataset.py
   - Reads a VoTT CSV and the images directory, reports:
     - total annotations
     - unique image count
     - classes and per-class counts
     - missing images referenced by the CSV
     - per-image dimensions (uses Pillow)
   - Usage example:
     python dataset_tools/inspect_dataset.py --csv Dataset/Dataset/vott-export.csv --images Dataset/Dataset --out dataset/summary.json

2- dataset_tools/validate_annotations.py
   - Validates each CSV row:
     - image file exists and is openable
     - bbox sanity (xmin < xmax, ymin < ymax)
     - bbox within image bounds
   - Writes an optional report CSV/list of errors.
   - Usage:
     python dataset_tools/validate_annotations.py --csv Dataset/Dataset/vott-export.csv --images Dataset/Dataset --out dataset/annotations_report.csv

3- dataset_tools/remove_corrupt.py
   - Walks the images dir, tries to open each image and `verify()` it with Pillow.
   - Moves corrupt/unopenable images to a target folder (default `dataset/corrupt`).
   - Usage:
     python dataset_tools/remove_corrupt.py --images Dataset/Dataset --out dataset/corrupt

4- dataset_tools/detect_duplicates.py
   - Two strategies:
     - MD5 byte-hash groups (works without extra deps)
     - Optional perceptual hash (pHash via `imagehash`) when `--use-phash` is enabled and the package installed.
   - Prints groups of files that are likely duplicates.
   - Usage:
     python dataset_tools/detect_duplicates.py --images Dataset/Dataset --use-phash

5- dataset_tools/stats.py
   - Computes per-class counts and simple bbox-area statistics (min/median/max).
   - Usage:
     python dataset_tools/stats.py --csv Dataset/Dataset/vott-export.csv

6- dataset_tools/split_dataset.py
   - Splits dataset images (by-image) into train/val/test sets using configurable ratios.
   - Copies image files into `dataset/images/{train,val,test}` and writes per-split CSVs into `dataset/annotations/{train,val,test}/{split}.csv`.
   - Note: it currently preserves VoTT CSV rows as CSV annotations. If you prefer YOLO TXT format (one label file per image), I can add conversion.
   - Usage example:
     python dataset_tools/split_dataset.py --csv Dataset/Dataset/vott-export.csv --images Dataset/Dataset --out dataset --train 0.8 --val 0.1 --test 0.1

7- dataset_tools/generate_data_yaml.py
   - Reads the CSV to collect class names and writes a small YAML manifest (default `dataset/data.yaml`) with keys: `train`, `val`, `test`, `nc`, `names`.
   - Usage:
     python dataset_tools/generate_data_yaml.py --csv Dataset/Dataset/vott-export.csv --out dataset/data.yaml

8- dataset_tools/README.md and dataset/ skeleton directories
   - Short README describing scripts and their purpose.
   - Created skeleton directories:
       dataset/images/train
       dataset/images/val
       dataset/images/test
       dataset/annotations

Known issues & caveats
----------------------
- Python is not available in this execution environment. Install Python 3.8+ locally and the required packages to use the scripts.
- The VoTT CSV uses absolute pixel coordinates. Most object-detection training pipelines (e.g., YOLO) use normalized center-based coordinates; conversion will be required before training.
- There is only one class `plate`, so `nc` in `data.yaml` will be 1.
- Duplicate detection using pHash requires `imagehash` and `numpy`.
- The split implementation copies images; for very large datasets you may prefer to write split index files or use symlinks instead.
